# ComfyUI 媒体浏览器 · 使用说明书 V2.13.5

一个**免安装的单文件小工具**：双击即可浏览 ComfyUI 出图目录，查看每张图的生成参数，支持标签管理、收藏分类、提示词搜索、重复图检测，并可一键把图片的工作流回传到 ComfyUI 重新生成。

## 本版亮点（V2.13.5）

**V2.13.5（2026-11-15）：提示词不再张冠李戴、查重能扫全库、六处每天硌人的交互一次修掉（修复 + 性能版）**

这版把 V2.13.4 之后累积的 **9 块改动**一次发出。最值得说的是五件：

① **有些图的提示词终于对得上画面了** —— 一类「带文本显示节点」的工作流（插件里的
`TE_text_display`）以前读出来的是**上一张图**的正文，还混进一整段负面提示词和一行
`SETTINGS: Quality=…` 调试参数。原因是这类节点存的文本有个「旧缓存自锁」，
真正这一次的文本另存在工作流的属性里。

| | 改前 | 改后 |
|---|---|---|
| 正向正文 | `POSITIVE: 2girls, …`（上一张图的） | 这张图真正的描述 |
| 混入的负面段 | 有 | 无 |
| `SETTINGS:` 调试尾注 | 有 | 无 |

> 只对「文本显示类」节点生效。你自己手改过的文本（`use_edited_text`）、以及正文里本来就写着
> `NEGATIVE:` 这种词的图，一律不动。

② **查重能扫全库了，而且快 6 倍** —— 查重弹窗多了「扫描范围」：**前 3000 张**（秒出，日常够用）
或**全库**。单张哈希从 42 毫秒降到 7 毫秒左右，全库约一分半，之后有磁盘缓存、再扫是秒级。
结论也更诚实：读不出来的坏图会单独报数，不再悄悄当成「不重复」。

| 场景 | 以前 | 现在 |
|---|---|---|
| 只想快看有没有明显重复 | 只扫前 3000 张（覆盖率约 25%） | 同样快，但界面说清「只扫了这些」 |
| 想确认整库干净 | 做不到 | 选「全库」，约 1.5 分钟，结论带分母 |

③ **六处「每天都会硌一下」的地方** ——

| 毛病 | 现在 |
|---|---|
| 勾了 20 张、再点「PNG」筛选（屏上只剩 6 张），批量条仍只写「已选 20」，删除时不说一声就删掉 14 张 | 批量条写「已选 20（14 张不在当前筛选内）」，删除确认框**明确警告**「其中 14 个已被当前筛选隐藏（屏幕上现在看不到），也会一起删除」 |
| 看完视频按 `→` 翻到图片，底部还挂着上一段进度条（拖它没反应） | 翻页即收掉进度条 |
| 打完标签后 `←` `→` `Esc` 不灵（焦点被输入框扣住） | 提交后自动离开输入框 |
| 按 `P` 收起详情面板，一翻页又自己展开 | 翻页保留你的开合状态 |
| 大图顶栏分辨率位置永远是空的 | 正常显示「1536 x 864」 |
| 按 F5 刷新永远回到根目录 | 回到上次所在的目录（目录没了才回落根目录） |

④ **「还有 N 个标签已失效」终于能清了** —— 你在应用外删掉图片、或把图换成别的东西之后，
标签表里那条键会一直占着，以前只能等换根或手工改 JSON。现在左栏那句话右侧多了「清理」按钮：
二次确认写明**只删记录、不动任何图片**，清完直接报「清掉几条」。
盘掉线、或者一次要清掉的比例过于离谱时，它会**拦下来并说明原因**，绝不闷头清空。

⑤ **搜索更快，手机上的「复制地址」能用了** —— 全库提示词搜索从 57 毫秒降到 9 毫秒上下，
边输边搜不再有顿感；局域网面板那个「复制地址」以前在 `http://192.168.x.x` 下**必然失败**
（它用的浏览器接口只在 https / localhost 才有），现在走统一出口，失败也有兜底。

> **前一版（V2.13.4）的内容同样在本包里**：LoRA 直达 C 站、不再凭空冒 LoRA、
> 常用目录可删、最近使用可清。详见下方「历史亮点存档（V2.13.4）」。
>
> ⚠️ 升级后**第一次打开会在后台重建一次索引**（解析口径变了），大库要几分钟；
> 期间能正常看图，只是提示词搜索会暂时只有部分结果。

## 历史亮点存档（V2.13.4，仅备查）

**V2.13.4（2026-11-11）：LoRA 直达 C 站、不再凭空冒 LoRA、能删的都能删了（存量收口 · 功能版）**

这版把 V2.13.3 之后累积的 **11 块改动**一次发出。最值得说的是五件：

① **每条 LoRA 右边多了两个 C 站入口** —— 大图详情面板里，每条 LoRA 右侧是一个小胶囊
`[R│C] ↗`：点 `R` 去 civitai.red、点 `C` 去 civitai.com。图里有 LoRA 哈希就按哈希精确匹配，
没有才按名字搜索；**匹配不上会直说**（胶囊降到七成透明度，悬停写明「只能按名字搜」），
绝不拿同名结果冒充确定匹配。查询在后台跑，不卡预览；结果缓存 7 天。

> 只把你的 LoRA **名字或哈希**发给 C 站，其他什么都不会上传；本地只**只读**打开 LoRA 管理器的
> 数据，不改它任何东西。桌面版里点开走系统浏览器，网页版里就是普通链接（中键 / 新标签页照旧）。

② **不再凭空冒出 LoRA** —— 有些图的提示词正文末尾粘着 `<lora:名字:1.45>` 这样的文字
（从别处拷来的残留）。ComfyUI 原生文本编码节点**只把它当普通文字**，并不加载 LoRA，
但旧版会把它列成一条 LoRA。实测全库 10053 张里 **540 张**有这种「幻觉条目」，共 1228 条。
现在原生节点里的标签只当文字处理，真正加载的 LoRA 照旧显示。

| 你可能看到 | 现在 |
|---|---|
| 详情里有一条 LoRA，但槽位里根本没勾选 | 不再显示 |
| 同名的真 LoRA 确实加载了 | 照旧显示（以真正执行的槽位为准） |
| 升级后第一次打开变慢一会儿 | 索引按新口径重建一次，之后正常 |

③ **根目录能删了、最近使用能清了** —— 这两处以前都是「只进不出」：

| 想做的事 | 怎么做 |
|---|---|
| 删掉一个不用的常用目录 | 点「根目录」下拉 → 把鼠标移到那一条上 → 点右侧出现的 `×`；菜单不会关，可以连着删几条 |
| 删掉当前正在看的那个目录 | **删不了**（它正指着索引），先切到别的目录再删 —— 会明确告诉你原因，不是点了没反应 |
| 从「最近使用」里去掉某一张 | 在该视图里右键卡片 →「从最近使用中移除」（**只删记录，不动原图**） |
| 一次清空最近使用 | 设置 → 行为 → 「最近使用」→「清空最近使用记录」 |

> 顺带修掉一个看不见的尾巴：删掉常用目录时，它在「隐藏文件夹」名单里的那一条也会一起清掉。
> 否则将来把同一目录重新加回来，以前藏起来的子文件夹会莫名其妙又冒出来。

④ **三件「别的图想藏、别的图想认」的功能** —— 在目录卡上右键「不再显示此文件夹」（9 秒内可撤销，
列表 / 计数 / 搜索 / 标签 / 查重一起跳过）；左栏收藏分类右键可**重命名**（撞名会先问要不要合并）
或**删除**（内容可选移到「默认」/ 取消收藏）；图片可生成**混淆副本**与**还原**副本，
副本落在原图同级的 `_混淆\` 里，原图一个字节不动。

⑤ **两处小东西** —— 大图左下角「像素快查」：按住 `Ctrl` 把指针移到画面上，指针旁开一个镜片把局部
放大到**像素级**（1 图像像素 = 1 物理像素，高分屏不糊），中键单击可钉住；以及 **exe 旁边不再冒
`ComfyMediaViewer-startup.log`** —— 正常启动零新增文件，只有真出错时才写一份留证。

> **前一版（V2.13.3）的内容同样在本包里**：手机 / 另一台电脑访问（局域网）、大图右键 5 项、

## 历史亮点存档（V2.13.3，仅备查）

**V2.13.3（2026-11-08）：手机也能看、右键补齐、提示词读全（存量收口 · 功能版）**

这版把 V2.13.2 之后累积的 **14 小块改动**一次发出。最值得说的是四件：

① **手机、另一台电脑也能看了（局域网）** —— 设置 → 数据 → **局域网访问**，打开开关就会显示一个
**6 位验证码**；同一 Wi-Fi 下，手机或另一台电脑在浏览器里打开面板上显示的地址、输入这 6 位码就能进
（**不需要摄像头扫码**）。

- **远端是只读的**：浏览、搜索、收藏、打标签、下载都能用；删除、换目录、重建索引会被拒绝并说明原因。
- **只在你的网络内**，不暴露公网；设备进过一次就记住，下次不用再输。
- **6 位码不是随便定的**：5 分钟过期、用一次立刻换新的；同一来源连错 5 次锁 2 分钟；
  同一个码累计错 10 次直接作废。验证码**只在这台电脑的面板上可见**，远端拿不到。

| 你可能会遇到 | 现在怎么处理 |
|---|---|
| 手机上打开是一片「输入验证码」 | 在电脑的设置面板里看那 6 位数字，输进去即可 |
| 忘了码 / 码过期了 | 面板上有「换一个」；旧码立刻作废 |
| 输错几次进不去 | 等 2 分钟（防止有人在你的网络上试码） |
| 想在手机上看别的文件夹 | 得先在电脑上换根目录（远端不许改） |

② **大图右键补齐到 5 项** —— 11-07 接管右键时只顾着「复制文件」，把系统菜单原本那些项
（图片另存为 / 在新标签页打开）一起弄没了，当时也没在更新日志里写明。现在补齐：

| 菜单项 | 做什么 | 谁能用 |
|---|---|---|
| **复制图片（不含元数据）** | 按像素复制，就是以前「贴一张图」的用法 | 都能用 |
| **复制文件（含元数据）** | 把**文件本身**放进剪贴板：粘到聊天窗口是文件、粘到文件夹是复制，PNG 里内嵌的工作流/提示词一个字节不丢，对方拖回 ComfyUI 还能复现 | 仅本机 |
| **复制文件路径** | 只复制路径文本（「把路径发给我，我去取这张」） | 都能用 |
| **用默认图片查看器打开** | 交给系统关联的看图程序，窗口会带到前台 | 仅本机 |
| **另存为原件（保留元数据）** | 弹系统保存框选路径，**字节原样**另存一份 | 仅本机 |
| 在文件夹中定位 | 资源管理器里选中它 | 都能用 |

> **「另存为原件」和顶栏「下载」不是一回事**：下载会把内嵌提示词**抹掉**、且固定落到下载目录；
> 另存为原件一个字节不改、路径由你选 —— 存进共享盘、U 盘、聊天附件目录时用它。
> 系统保存框弹不出来（非 Windows / 无图形环境）时会自动退回「浏览器原样下载」，不会报假失败。

③ **提示词读全了** —— 以前有四类工作流的提示词会读空或读半截：

| 现象 | 实际是什么 | 现在 |
|---|---|---|
| 正向、负向**两栏都空**，像这张图没写提示词 | Impact Pack 的**通配符节点**把正文放在 `wildcard_text` / `populated_text` 两个专用字段里，旧版一个都不认 | 两栏都能读（优先取真正送进采样器的那份） |
| 只读到半截、前半段是触发词 | MOSS 布局工作流：旧逻辑先收到 LoRA 触发词就返回了 | 正文无条件取全，触发词排在最前 |
| 同时接了两条提示词分支时，读出来是 A+B 拼一起 | 中间的开关节点没按 `select` 选路 | 只走被选中的那一路 |
| LoRA 显示 15 条，其中 10 条重复 | WeiLin 的 `temp_lora_str` 是编辑器里的**暂存区**（待加入 + 已生效的副本），不是执行结果 | 只算真正执行的 `lora_str`，5 条就是 5 条 |

**「读不到提示词」不再是一个笼统的空**：四种成因现在分开讲 —— 打标 / 反推节点给的是**上一轮的缓存**
（会明确标「上次运行，仅供参考」，不冒充这张图）；随机抽取节点会**点出清单是哪个文件**；
展示节点不算产出者（不再把模型加载器误报成来源）；真正没写提示词的图**如实说没有**。
全库复核 49 张空正向：**45 张有了说明**，4 张确实没有。

④ **三处手感** —— **新图浮窗**（边翻老图边看新图，不用退出当前这张）、
**外部图片拖进窗口直接打开**（不必先进文件夹）、**关大图不再被拽回列表顶部**（从哪张关的，就停在哪张）。

> **前一版（V2.13.2）的内容同样在本包里**：三种以前读不出的 LoRA 存法、多段流每段参数各归各段、
> 提示词字数统计。详见下方「历史亮点存档（V2.13.2）」。

> **V2.13.0 的启动提速等内容同样在本包里**：双击到能用 **111 秒 → 5.6 秒**、左栏收放
> 159fps、网格淡描边与滚动时显形文件名、右下角位置刻度。详见下方历史亮点。

## 历史亮点存档（V2.13.2，仅备查）

**V2.13.2（2026-11-03）：元数据不再读错、多段流看得全、提示词多一个字数（功能版）**

① **以前读不出来的 LoRA，现在能读出来了** —— 有三种写法以前一条都读不到，现在都能读：

| 你可能会遇到的现象 | 实际是什么写法 |
|---|---|
| LoRA 区块整块不显示，图里明明有 10 条 | WeiLinPromptUI 把整张槽位表塞进 `lora_str` 字段（独立节点，不在模型连线上） |
| 一条都不显示（换模型精修的多段流） | `LoadLoraModel` 把槽位摊成 `loras.0.lora_name` 这种点号键 |
| 只显示 1 条，其余留在提示词里 | `<wlr:名字:权重:…>` 内联在正文开头 |

同一个 LoRA 也不会再显示两遍（有的图两种写法同时存在，以前 **5 条会被显示成 9 条**）。
两张你报过的样图已在门禁里做了端到端断言（10 条 / 2 条）。

② **多段流：每段的采样参数各归各段** —— 这是本版**最要紧**的一处，因为它以前是**读错**而不是不好看。
老版本把「采样器 / 步数 / CFG / 种子」只从**第 1 段的采样器**取一份显示；两段用不同采样器时，
屏幕上那行参数是第 1 段的，第 2 段真实的参数一项都不出现 —— 照着界面去复现，出不了同一张图。
现在改成：

- **每段用的模型都列出来**（段号方块 + 完整文件名，一段一行），不再是缩在字段表里的灰色小字；
- **下方一张「采样链路表」**：`序号 / 采样器 / [尺寸] / 步 / CFG / 种子`，靠列对齐对照，6 段也只占 6 行；
- **尺寸列按情况出现**：各段尺寸一致就走 5 列（大多数情况，宽松好读）；真的不一致
  （比如 `1216×832` 放大到 `1824×1248`）才加「尺寸」列，每段写自己那一段的真实尺寸；
- **五项参数完全一致就不出表** —— 沿用原来那四行，单模型的图**外观一个像素都不变**；
- 哪一段读不到参数就显示 `—`，**绝不拿第 1 段的值顶上**（那正是以前的错法）。

③ **提示词多一个字数** —— 「正向提示词」标题右边多一行小字，例如 `1,650 字`。
数字是**去掉空格和换行之后**的字符数（中文 1 字算 1，ComfyUI 里的缩进和换行不算内容）；
鼠标停上去能看到完整口径：「去空白 1,650 字 · 含空格与换行 1,889 字符 · 有内容的行 12」。
负向提示词不显示计数。

> **同包还含 V2.13.1 十一个试用包的全部内容**（V2.13.1 只发过源码包，没出过安装包）：
> 长列表滚动更省力（3,000 张滚动一帧 **50.5 → 15.4 毫秒**）、开大图不再闪一下、
> 大图顶栏的「删除」在窄窗口下不再被裁掉、快速连按删除不会重复发请求、
> 只有 API 提示词（没有 UI 工作流）的图也能推回画布、推送画布报 `e is not iterable` 已修掉、
> A1111 / Forge 与 AnimaArtistPack 那两类图的底模与提示词补读。

## 历史亮点存档（V2.13.0，仅备查）

### V2.13.0（2026-10-27）启动快 20 倍、左栏真的顺了、网格更好认（功能版）

① **启动不再要「两分钟」** —— 双击到能用，实测 **111 秒 → 5.6 秒**。两处根因都修了：一是无控制台打包版的**日志在自我复读**（一行里塞了 1415 个时间戳，每秒往硬盘写 296 KB），二是启动时要对 49 个端口逐个「敲门」且**没有超时**，安全软件一拦就是两秒一个。现在改成先在本地试占端口（微秒级、不发包），只对真正被占的端口去问身份。

② **左侧栏收放：从「顿挫」到「丝滑」** —— 收起 / 展开时网格不再整屏重排（布局耗时 50.5 → **9.7 毫秒**，帧率 128 → **159fps**）；上一版「滑完画面才变宽」的跳变（一帧跳 260 像素）也消掉了 —— 现在**点下去布局就到位**，侧栏和卡片各自平滑补间（158fps / 长任务 0）。

③ **网格更好认** —— 卡片圆角更收敛、深色与亮色两套主题都加了一道很淡的描边，满屏时每张卡都有自己的轮廓，又不会变成一排「框」。

## 历史亮点存档（V2.12.5 及更早，仅备查）

> 以下为 **V2.12.5 及更早**的亮点，保留下来是怕有人升级后想念老用法；**本版（V2.12.9）的新东西都在上面**。

- **C 盘不再被悄悄吃掉；删不掉、读不到这些事也开始说实话（V2.12.6）**：
  以前这个工具**每启动一次**都会在系统临时目录里解包一份自己，正常退出会自动删掉，但只要**被强制结束**
  （任务管理器结束进程 / 关机 / 崩溃）就删不成 —— 实测这条路曾把临时目录堆到 **173 个、约 5.2 GB**，
  足以吃满 C 盘。现在改成**每次启动顺手打扫上一次留下的**（只认自己留下的、带归属标记的那一种），
  累积上限恒为 1 份。另外**「重启程序」也不再白屏**了 —— 重启时新进程会继承一批打包相关的环境变量，
  让它误以为「已经解包好了」而去复用旧目录，而旧进程恰好正在删它（实测新实例的资源目录 **11 项被删到 4 项**），
  现在起新进程前先清干净。
  同一版还把几处**「读不到」和「本来就没有」混为一谈**的地方分开了：以前读不出生成信息时会打一句
  「这张图没有内嵌生成信息」，可其实可能只是**这一次读取失败**（比如文件正被别的程序占用）；
  现在两种情形分开提示，并给一次「重试」的机会。顺带还修了：标签树**不再静默丢弃**（扁平标签超过 14 个
  以前是直接不显示、连「还有 N 个」都不给，现在多一行「更多」可展开）；网络路径（`\\NAS\...`）的
  **面包屑不再点哪一层都跳错**；长文件名、长路径**悬停可以看全**。
- **不想看的图可以自动挡掉了 —— 内容安全（NSFW · V2.12.5）**：给工具加了一双「眼睛」，它会给每张图打一个
  **内容风险分**。
  可以在设置 →「内容」页（顶栏也有一组同样的按钮）自己选三档：**隐藏**（有风险的图从列表里剔除）、
  **模糊**（封面是毛玻璃，点单张揭开 —— **默认档**）、**显示**（不做任何处理）。
  挑常用那一档就行，**不用来回开关**。三点值得知道：
  **① 线稿类（模型输出里的 `drawings` 这一类）不参与打分**；
  **② 万一判错了可以在大图里人工纠正**（标成「安全 / 不安全」，重新检测也不会冲掉你的纠正），
  而且这些记录**跟着目录走** —— 换个盘、挪个文件夹也不会丢（见下一条）；
  **③ 模型随包带走**（离线可用、不上传任何东西），代价是单文件 exe 由 **14.5 MB 变成约 43 MB**
  （自带推理引擎 + 约 10 MB 模型）。万一本版没把推理引擎打进去，它会**如实告诉你**，绝不假装查过。
  **④ 没建过检测库时不会「假装成功」**：如果引擎装好了但你从没跑过检测，工具条会变成**琥珀色**并
  提示你「还没有检测结果、点击去开启」，点一下直接跳到设置页的内容页签开始检测 ——
  不会出现「点了隐藏、弹了成功提示、实际一张都没被滤掉」这种情况。若**连引擎都没装**，
  工具条会**去色变灰**并说明原因（红眼不再冒充「正在保护」）。
  **⑤ 检测只针对静态图片，视频不参与打分** —— 视频在「隐藏 / 模糊」两档下仍按原样显示。
  这是有意的取舍（抽帧 + 逐帧推理的代价远大于收益），不是漏检。

  现在会**按文件指纹**把这些一一匹配回来（包括枯燥的移动路径记录），开起来就自动迁，
  设置页也留了**手动触发**的入口。注意：**在软件内部切换根目录本来就不会丢**（数据是按目录分文件存的），

- **一批「看起来没坏、其实在骗你」的隐患修掉了（V2.12.5）**：借着一次全量代码审计，把几类最容易让人白忙活的问题修了 ——

  一直被误读成失败）；**② 写盘失败但仍提示成功**（回收站还原、标记、收藏、最近浏览这四处，
  现在失败会如实告警，不再让你以为存住了）；**③ 快速连点换目录时画面会跳回上一个目录**
  （慢的旧响应回来把新结果覆盖了）；**④ 对话框的「身份」补上了** —— 读屏软件现在知道这是个弹窗、
  焦点关掉后也会回到你按下的那个按钮；**⑤ 没有回收站的盘**（U 盘 / 网络盘 / exFAT）
  以前会**静默永久删除**，现在会提示并改用工具自带的回收站。
- **配方里的正向提示词不再重复一遍（V2.12.5）**：有些工作流（例如 Krea2 系列）会把「风格词 + 正文」先拼好，
  再送到一个**专门用来显示**的节点；这类节点习惯把拼好的整句**写回自己的输入框**留作记录，
  同时还连着上游的原文。以前两处都算数，于是详情栏出现「整句 + 前半段 + 正文」三块，
  **肉眼看上去就是正文重复了一遍**（实测一张图 2815 字 ≈ 正确值 1407 的两倍）。
  现在的规矩是：**显示用的节点只要还连着上游，就只读上游原文**，它的缓存不再参与；
  如果整条链路只有缓存、读不到任何文字，就自动退回老办法，绝不显示空白。
  全库 9080 张逐张对照，**没有一张因为这次改动读不到或读错**。

  整个动画里内部文字宽度还会反复重算（出现 7~8 个不同值）。

  动画时长也从 200ms 校正到面板级该用的 **280ms**。
- **左栏开合进一步顺滑（2026-10-20 · 二次优化）**：上一次解决的是「起手抖一下」，
  这次是「滑动过程中整屏卡片跟着重排」。原因是左栏位移改的仍是**布局属性**，280ms 里每一帧

  所以看着不卡，但有一下明显的「顿」。现在动画期间左栏**只在合成层里平移**，
  内容区宽度到动画结束才一次性让位；折叠把手也不再走布局属性，收起时那 1px 的宽度抖动一并消掉。
  实测同一次开合的重排耗时降到约**五分之一**、帧间隔从 18.7ms 收到 6.4ms，
  而开合后的终态（内容区宽度、列数、滚动高度）与以前**完全一致**。

## 一、快速开始

1. 双击 `ComfyMediaViewer.exe`（首次启动需等 5~10 秒，属正常现象）；
2. 程序会自动打开浏览器访问 `http://127.0.0.1:8765`；
3. 首次使用会**自动搜索本机的 ComfyUI\output 目录**，找到即自动加载；
   - 没找到时，点左栏 **位置 → 根目录** 下拉里的 **📂 选择文件夹…** 手动指定（会弹出**网页内置目录选择器**：可切换盘符、点文件夹名进入、点「↑ 上级」返回，选中后点「确定」即可），或用 `--root` 参数启动。

> 程序启动后会在**系统托盘**（右下角）显示图标：左键/双击打开浏览器；右键菜单可打开浏览器、打开数据目录或退出程序。重复双击 exe 只会唤回已打开的窗口，不会多开后台进程。

### 可选启动参数

```
ComfyMediaViewer.exe --root "D:\我的图片" --port 8888
```

- `--root`：指定浏览的根目录（显式指定时跳过自动探测，启动更快）
- `--port`：指定端口（默认 8765，被占用时自动后移）
- `--no-browser`：不自动打开浏览器
- `--lan`：局域网模式（等价于在设置里打开「局域网访问」；日常用图形开关即可，见第十一节）

> 无需安装 Python 或任何环境，整个程序只有一个 exe 文件。

| 子文件夹 / 返回上级卡 | 分页模式下只在**第 1 页**占一格（第 2 页起整页都是内容）；要进子文件夹也可以直接点工具条上的**面包屑**路径，不必回到第 1 页。无限瀑布流不分页，所以一直显示在网格开头 |
| 卡片大小 / 字体大小 | **⚙ 设置 → 外观** 里拖动滑块（字体大小同时缩放顶栏与侧栏）；上方还有 **紧凑 / 舒适 / 宽松** 三档一键切 |
| 缩略图 裁切 / 适应 | **⚙ 设置 → 外观 → 缩略图**：适应=完整显示整张图（默认），裁切=铺满卡片 |
| 看清翻到哪儿了 | **滚动时卡片底部会浮出文件名**（松手约 0.4 秒收起），右下角同时显示「第 N / 共 M 张 · 百分比」；1.2 秒不动刻度只留百分比。想一直看到文件名就去 **⚙ 设置 → 外观 → 卡片信息 → 常显文件名** |
| 自动刷新 | **⚙ 设置 → 行为 → 自动刷新**（带 ✓ 表示已开启）：**每 5 秒**轮询目录指纹，**出图后网格自动出现新文件**；从其他窗口切回本工具时会立刻补查一次 |
| 立即刷新 | 顶栏 **刷新** 按钮（或按 `R`，V2.10.7）：**立刻重扫当前目录**，不等自动刷新。刷新期间按钮转圈、底栏报「正在刷新当前目录…」，完成后 **toast 报「已刷新（当层 N 个文件）」**（若提示词索引正好在后台重建，底栏会由扫描器改播「正在扫描生成参数…」，那是真在跑的进度，优先显示；此时兜底文案是「已刷新 · 当层 N 个媒体文件」），连点只算一次；**当前选中的图 / 打开着的大图刷新后仍在原处** |
| 按参数筛选 | 左栏 **筛选**：时间范围 / 尺寸 / 模型 / 采样器 |

**大图右键 5 项**（V2.13.3 · 11-08，按菜单顺序）：

1. **复制图片（不含元数据）** = 按像素复制（老的「贴一张图」用法）；
2. 🔒 **复制文件（含元数据）** = 把这张图**文件本身**放进剪贴板（粘到聊天窗口是文件、粘到文件夹是复制，PNG 内嵌的工作流 / 提示词一个字节不丢，对方拖回 ComfyUI 还能复现）；
3. **复制文件路径** = 只复制路径文本（远端也能用，「把路径发给我，我去取这张」）；
4. 🔒 **用默认图片查看器打开** = 交给系统关联程序（窗口会带到前台）；
5. 🔒 **另存为原件（保留元数据）** = 弹原生保存框选路径，**字节原样**另存一份 —— 与顶栏「下载」不同，下载会抹掉内嵌提示词且固定落到下载目录。

> 分隔线以下是**在文件夹中定位**。图片被模糊（NSFW 未揭开）、视频、空白处右键仍是系统菜单 —— 模糊的图先点左上角眼睛再看。

## 四、一键回传 ComfyUI（V2.0 新增 · V2.8 起可送进已打开的页面）

在**大图页**，带生成参数的图片会显示两个回传按钮：

| 按钮 | 功能 |
|---|---|
| 🔄 ComfyUI | 把该图内嵌的工作流**装载到画布**（只装载、不执行），你在 ComfyUI 里确认后手动 Queue 即可重跑 |
| ⬇ 工作流 | 导出可读的工作流 JSON 文件（提示词/模型/采样器/LoRA 已按模板整理） |

**「🔄 ComfyUI」会自己挑一条路走：**

1. **检测到你已经开着 ComfyUI 页面 → 直接送进那个页面**（V2.8 新增，推荐）。
   不再弹新窗口，工作流直接在你正开着的那个 ComfyUI 标签页里**自动载入成一张新画布**，
   你原先在编辑的工作流不受影响，可以随时切回去。
   前提是装过一次**桥接脚本**：点提示里的「安装桥接脚本」，会**弹出一个说明弹窗**讲清收益与三步操作，
   点「立即安装」即可——脚本会写进 ComfyUI 的 `custom_nodes/ComfyMediaViewer-Bridge/`；
   装完还会再弹一条显眼的「**最后一步：完全关闭 ComfyUI 再启动一次**」，照做并刷新页面就生效了。
   也可以跳过安装按钮，把 `frontend/bridge/comfy-cmv-bridge.js` 直接拖进 Tampermonkey / Violentmonkey。
   没点到提示也没关系，下次点「🔄 ComfyUI」还会再出现。
2. **没检测到已打开的页面 → 照旧另开一个独立窗口注入**（原行为）。
   程序启动一个带调试端口的独立 Edge（空 profile，不影响你日常浏览器）。这条路不需要装任何东西。

> 前提：ComfyUI 正在运行（默认 127.0.0.1:8188）。
> 两条路都**只装载、不执行**，不会自动生成，确认参数后手动 Queue Prompt 即可。
> 送过去的工作流若引用 `LoadImage` 的图，需该图已存在于 ComfyUI 的 `input/` 目录（本版只搬工作流、不搬图片）。

**画布上已经开着工作流？**（V2.8 起：不会覆盖，自动新开一张）

送进已打开页面时，工作流会**直接载入**，全程不再询问：

- **不会覆盖你正在编辑的工作流**。实测 `loadGraphData` 不会替换当前画布，ComfyUI 会把新工作流
  **另开一张画布**承接，原来那张原样留着，随时切回去继续编辑
- 载入完成后，ComfyUI 右上角会出现一条「已载入：xxx」的提示，告诉你送到了

> 早期版本这里会弹一张「载入 / 忽略」的小卡片，理由是「怕覆盖」。真机实测确认**不会覆盖**之后，
> 这张卡片已整体移除 —— 没有理由为一件不会丢东西的事拦着用户点确认。
> 更早的版本用的是浏览器自带确认框（`confirm()`），它会**冻结整个 ComfyUI 页面**（对话框挂着时页面
> 的定时器和请求全部停摆），被取消后还可能再也弹不出来，看起来就像「推送失灵」。

**装完不生效？**（V2.8 桥接排障）

| 界面提示 | 原因 | 怎么办 |
|---|---|---|
| 「…但 ComfyUI 还没重启，页面没加载它」 | 脚本文件已写好，但 ComfyUI 没重启 → 页面根本拿不到脚本 | **关掉 ComfyUI 再重新启动**。注意：**重装脚本没有用**，必须重启 |
| 「ComfyUI 里的桥接脚本还是旧版，重装一次才能用上…」 | 装过的是旧版本脚本，ComfyUI 不会自动升级 `custom_nodes` 里的文件 | 点提示里的「重新安装」，**装完再重启一次 ComfyUI** |
| 「桥接已就绪，只是没检测到你开着的 ComfyUI 页面」 | 扩展已生效，缺的是开着的页面 | 点提示里的「打开 ComfyUI」，在**你常用的浏览器**里打开并留着这个标签页 |
| 没有提示，但仍弹独立窗口 | 那个 ComfyUI 页面是在装脚本**之前**打开的 | **刷新一次**该页面（已开着的页面不会自动加载新扩展） |
| 「回传了，但 ComfyUI 那边始终没反应」 | 载入失败会自动重试并逐次弹提示（V2.8.4 起） | 看 ComfyUI 页面里的提示；若最终提示「已放弃载入」，多半是这张图的工作流本身有问题（也可能是桥接脚本过旧，按上一条重装一次） |

> 搜狗、360 等 Chromium 内核浏览器同样可用；若浏览器处于「兼容模式（IE 内核）」，请切到高速模式。

## 七、搜索

顶栏搜索框，两种模式：

- **文件名**：按文件名关键词过滤；
- **提示词**：搜索图片内嵌的正向/负向提示词、模型名、LoRA 名（输入有防抖，无需担心打字卡顿）。首次使用自动建立索引，之后**秒搜**；索引每 30 秒自动增量刷新，刚出的图很快可搜到。JPEG/WebP 也纳入索引。

## 八、重复图检测（V2.0 新增 · V2.13.5 可扫全库）

设置 →「数据」→「分析工具」→ **重复图片检测**：扫描当前目录（含子目录）中的相似/重复图片（感知哈希 + 汉明距离，截图连拍、不同格式的重复导出都能识别）。结果按组显示，每组勾选要保留的一张，一键删除其余（去向跟随「删除去向」设置）。

### 扫描范围（V2.13.5）

弹窗顶部多了一个「扫描范围」下拉，**你的选择会被记住**：

| 选项 | 扫多少 | 耗时（1 万张级图库实测） | 适合 |
|---|---|---|---|
| **前 3000 张（快）**（默认） | 最多 3000 张 | 几秒 | 日常快看有没有明显重复 |
| **全库（首次慢，之后走缓存）** | 整个当前目录树（一万多张） | 约 1.5 分钟；之后有缓存，再扫是秒级 | 想确认整库干净 |

- **「前 3000 张」是按目录遍历顺序取的**，不保证是「最新的 3000 张」—— 想确认整库干净就选全库；
- 界面会如实写清这次扫了多少：选「前 3000」时标**已达扫描上限**，选全库才标**已覆盖全库**；
- **读不出来的坏图会单独报「有 N 项没查成」**，不会被悄悄当成「不重复」（这也是「结论看着是 0 组、实际可能没查全」的常见来源，现在直接写出来）。

**V2.13.5 起单张哈希从 42 毫秒降到 7 毫秒左右**（解码改为多线程，且只在真有方向信息时才把图转正）。
哈希结果缓存在数据目录的 `dupe_hashes.json` 里，按「路径 + 修改时间 + 大小」判定 ——
增删改过图之后，只重算变动的那几张，其余直接命中缓存。

## 十、删除与回收站

**删除去向可以自己选**（V2.8.3 新增）—— **⚙ 设置 → 行为 → 删除去向**（V2.10.5 前在左栏「外观与操作」）：

| 去向 | 删除后文件去哪里 | 怎么还原 | 说明 |
|---|---|---|---|
| **应用内回收站**（默认） | 软件自己的回收站 | 顶栏 `⋯ 工具 → ♻ 回收站` | 保留 **30 天**；删完还能一键「撤销」；收藏 / 标签 / 标记随文件暂存，还原时恢复 |
| **Windows 回收站** | 系统回收站 | 资源管理器 | 与在资源管理器里按 Delete 完全一致；**不**出现在软件内「回收站」里；某个盘不支持回收站（exFAT、网络盘）时自动退回应用内回收站，并提示退回了几个 |

**这个设置会被记住**：选择立即写盘，**关掉软件再打开仍然是上次选的**，不会被重置。设置文件在：

```
%LOCALAPPDATA%\ComfyMediaViewer\settings.json
```

（把上面这行粘进资源管理器地址栏回车即可打开所在文件夹；也可以右键任务栏托盘图标 → **打开数据目录**。单文件版、桌面版、源码直启**共用同一份设置**，换启动方式不会跑丢。）

下面的操作，**去向跟随这个设置**：

| 操作 | 方式 |
|---|---|
| 删除单张 | 大图页"删除"按钮或 `Delete` 键，确认后按设置的**去向**移入回收站 |
| 批量删除 | 批量模式选中 → "删除所选"，**单次请求完成**（上百张也很快） |
| 查看回收站 | 顶栏 `⋯ 工具 → ♻ 回收站`：按时间列出已删文件（**只含应用内回收站去向的文件**） |
| 还原 | 回收站中单条"还原"或"全部还原"（原名被占用时自动加后缀） |
| 彻底删除 | 单条"彻底删除"或"清空回收站"（**不可恢复**，需二次确认） |
| 自动清理 | 回收站文件保留 **30 天**后自动清理 |

- 删到**应用内回收站**：收藏、标签、标记随文件一起暂存，还原时恢复；搜索索引同步清理；
- 删到 **Windows 回收站**：不动你的收藏 / 标签 / 标记 —— 从系统回收站还原后文件路径没变，
  这些数据继续有效（这也是删之前不去清它的原因）；
- 大文件跨盘删除是"复制到回收站 + 删除原文件"，耗时会略长。

### 批量模式

首页**网格空白处点右键** → "✦ 批量选择"。批量模式下单击卡片即勾选，底部浮出操作栏：**已选 N / 全选 / 清除 / 对比（2-4 张并排对比） / # 标签 / 导出… / 删除所选 / 退出批量**。

- **对比**：2-4 张图并排显示，可拖动分隔线对比细节；
- **导出…**：把所选文件复制到指定文件夹。

> **筛选会改变「实际删掉几张」（V2.13.5 起会明说）**：勾了 20 张、再点「PNG」筛选让屏上只剩 6 张时，

## 十一、局域网访问（手机 · 另一台电脑 · 2026-11-07 开通）

> **已开通（2026-11-07）**：在 **设置 → 数据 → 局域网访问** 里点「开启」即可。
> 面板上会出现一组 **6 位数字验证码**；另一台设备（手机 / 平板 / 电脑）连同一个 Wi-Fi，
> 用浏览器打开面板上的地址、输入这 6 位数字就进来了 —— **不需要摄像头扫码**，
> 也不用手抄那串很长的令牌。

**怎么进（三步）**

1. 电脑上：**设置 → 数据 → 局域网访问 → 开启**，记下面板上的地址（如 `http://192.168.1.20:8765/`）和 6 位验证码；
2. 另一台设备：用浏览器打开这串地址（地址也可以点「复制地址」发给自己）；
3. 输入 6 位数字 → 自动进入。验证页在电脑和手机上都只有一个输入框，回车或点「进入」都行。

> 地址里**不带令牌**，就是 `http://` + 局域网 IP + 端口（如 `http://192.168.1.20:8765/`），
> 只有 25 个字符左右，可以直接照着敲进手机浏览器；点「复制地址」发给自己也行。
> **V2.13.5**：这个按钮在 `http://192.168.x.x` 这类局域网地址下以前**必然失败**
> （它用的浏览器接口只在 https / localhost 才有）；现在改走服务端统一出口，失败也会说明原因。

**验证码的规矩（也就是安全边界）**

- **5 分钟内有效**，用过一次立刻换新 —— 同一个码不能进第二次；
- 同一台设备连错 5 次，锁 2 分钟；同一个码累计错 10 次（换设备乱试也一样）直接作废，
  电脑面板上会换成新码；
- 验证码**只在这台电脑的面板里可见**，手机 / 另一台设备读不到；
- 进去之后令牌记在 cookie 里，**最长记住 1 年**，重启电脑也不用重新输；
- 面板上「换一个」= 立刻作废当前码；「重新生成令牌」= 此前连过的设备**全部失效**，
  都要重新输码（设备丢了 / 借给别人用过，就靠这个把口子收回来）。

**它做了什么**

- 开启后程序会**同时监听局域网**（`0.0.0.0`），关掉后立刻回到只听 `127.0.0.1`；
- 令牌存在数据目录的设置里，重启程序不会变（已配对的设备不用重来）。

**手机端是只读的（有意为之）**

手机可以：浏览、搜索、看大图与视频、收藏、打标签、下载。
手机不能：删除 / 移入回收站、换根目录、打开本机目录选择器、重建索引、推送工作流、
在电脑上启动程序。这些操作会提示「远程只读：这一步需要在电脑上操作」。

> 判断依据是**请求从哪来**，不是账号：从这台电脑的浏览器（`127.0.0.1`）操作一如既往，
> 手机 / 平板 / 另一台电脑自动进只读。所以不存在「在手机上误点删除、图没了」。

**边界与注意事项**

- 只适用**同一个局域网 / 同一 Wi-Fi**，不暴露到公网。人在外面想连家里，请用 Tailscale
  这类私有组网工具，不要做端口映射；
- 局域网内是明文 HTTP（同 Wi-Fi 的人理论上能嗅探令牌）。家里可用，**咖啡厅 / 公共 Wi-Fi 别开**；
- 首次开启若弹 Windows 防火墙提示，请选「允许」（勾专用网络即可）；点了「取消」的表现是
  手机一直转圈 —— 回到设置页关掉再开一次即可重新触发提示；
- 翻页：电脑用左右方向键或点箭头；手机还可以在**大图上左右滑动**（图片没放大时生效）。

## 十三、时间轴视图（V2.9.0 新增）

一句话：**「上周三那批图在哪」——不用再一路往下翻，点一下就到。**

### 怎么进

内容区工具条的 **视图** 里多了一个时间轴按钮（网格 / 列表 / **时间轴**），
也可以直接按 **`T`** 键来回切换（大图页里的 `T` 仍是「聚焦标签输入框」，两者互不干扰）。

### 长什么样

- 当前列表**按日期分组**、自上而下排开，每一组有一个**吸顶标题行**：
  `今天 · 周六 · 65 张`。往下滚时，当前那一组的标题会一直**吸在顶部**，随时知道自己在哪一天。
- **点标题行 = 折叠这一组**（再点一次展开）；某组的缩略图合起来也会显示成一个整行。
- 一组太长时默认先显示 60 张，末尾给一条 **「展开全部（还有 N 张）」**，点一下铺满。
- 右侧是**日期索引栏**：只列出你当前这批结果里**真实有图的日期**和各自的张数。
  它还会跟着滚动自动高亮你正在看的那一天。窗口窄（≤900px）时它收成一个「索引」按钮，点开是覆盖式抽屉。

### 五档粒度（顶部「粒度」按钮）

| 粒度 | 分组方式 | 适合什么时候用 |
|---|---|---|
| 时 | 同一天里再按小时切 | 今天连出了好几批，想分细一点 |
| **日（默认）** | 每个自然日一组 | 主场景 |
| 周 | 自然周（周一起算） | 回看一周的产出 |
| 月 | 每个自然月一组 | 长周期总览 |
| **批** | 按出图间隔自动聚成「一次生成一批」 | ComfyUI 的原生心智：**一次 Queue = 一批** |

「批」这一档会顺带告诉你**这批跑了多久**（如 `1 分 4 秒 · 65 张`），
间隔阈值默认 5 分钟 —— 如果你用大模型、高步数，单批本来就会跑很久，
慢到被切成好几批时可以调大阈值（改 `TL_BATCH_GAP`，单位秒）。

### 怎么快速回到某一天

三条路，任选：

1. **点右侧日期索引栏**里那一天；
2. **`[` / `]`** —— 上一组 / 下一组（键盘，不用离开手边）；
3. **「回到今天」**按钮 —— 当前结果里没有今天的图时，这个按钮是灰的（鼠标悬停会说明原因）。

> 使用「分页」展示方式时，「今天」可能不在当前这一页 —— 这时点索引栏会**自动切到无限瀑布流**再跳过去，
> 不用你自己先切模式。
> 跨度很大时（例如从最新一批直接跳到很久以前），中间那些日期会**自动折叠成标题行**，跳到位后
> 点标题即可展开 —— 否则要一口气铺出几千张缩略图，得等好几秒。

### 它和别的东西怎么搭配

- **和筛选是叠加的**：搜索、标签、收藏、格式、工作流类型、时间范围……选完之后时间轴会**按新结果重新分组**。
  例如左栏把「时间范围」选成**本周**，时间轴就只剩本周那几天。
- **和「展开文件夹」互斥**：展开文件夹时列表是按文件夹数排的，两套分组口径叠在一起会打架，
  所以切到时间轴时会自动收起文件夹（回到网格/列表不受影响）。
- 组标题行是**分隔用的合成行**：不算进「N 项」计数、**不会被大图左右翻页选中**、
  批量「全选」也不会把它算成一张图。所以「上一张 / 下一张」跨天很顺，不会卡在日期行上。
- 计数在时间轴下会变成「**5 天 · 74 项**」这种写法，一眼看出摊了多少天。

## 十五、数据存储与迁移

所有数据保存在 `%LOCALAPPDATA%\ComfyMediaViewer\`：

| 文件/目录 | 内容 |
|---|---|
| `favorites.json` | 收藏与分类 |
| `tags.json` | 标签 |
| `settings.json` | 界面设置，以及常用目录列表（存于其 `roots` 字段内）、上次浏览目录等 |
| `prompt_index.json` | 提示词搜索索引（可删，删后自动重建） |
| `thumbs\` | 缩略图缓存（超 512MB 自动按最久未用清理；启动时查一次，之后每 6 小时一次） |
| `trash\` | 应用内回收站 |

- **便携模式（V2.10.5 新增）**：设置 →「数据」→「数据目录」可在**用户目录**（默认，
  `%LOCALAPPDATA%\ComfyMediaViewer`）与**程序目录（便携）**（程序旁的 `cmv-data\`）之间切换；
  切换会弹**三选一**（复制过去 / 移过去 / 不迁移），**须重启程序生效**。
  两种落点各有取舍，没有哪种绝对安全：

  | 位置 | 好处 | 代价 |
  |---|---|---|
  | **用户目录**（默认） | 换程序版本、把程序挪到别处，数据都不受影响 | 在系统盘上，**重装系统或换电脑会丢**，需自己备份 |
  | **程序目录（便携）** | 整个程序文件夹拷到 U 盘 / 另一台机器，设置、收藏、标签、索引一并带走 | 跟着程序走，**程序文件夹被删掉或挪走，数据也跟着走** |

  桌面版（Tauri 壳）同样支持：它把后端释放到系统盘临时目录运行，但会把自己 exe 的真实位置
  告知后端，所以便携数据仍然落在**你放程序的那个文件夹**里（V2.10.7 修正）。
- **备份/迁移**：拷贝对应 json 文件即可；
- **彻底清理**：删除 `%LOCALAPPDATA%\ComfyMediaViewer` 整个文件夹；
- 卸载软件只需删除 exe 本身。

## 十六、图片混淆 / 解混淆（2026-11-08 新增 · 2026-11-09 换成无损 PNG）

把一张图**打散成乱色块**再发出去，防剧透、防顺手转发；收到别人发来的「小番茄混淆图」，
也能一键还原。算法与 <https://xiaofanqiejiehunxiao.com/> **逐像素互通**。

算法只有一套，跑在**页面里**（Web Worker，1200 万像素秒级出结果）；后端只负责把算好的
PNG 落到 `_混淆\`。那样桌面版也能可靠出文件（WebView 的「下载」不保证弹保存框），
而且不会出现「两套算法各算各的、哪天悄悄对不上」。

### 怎么用

| 在哪 | 怎么点 | 得到什么 |
|---|---|---|
| 网格 | 右键卡片 →「生成混淆副本（小番茄）」/「还原混淆副本」 | 一份**文件**，落在原图旁的 `_混淆\` |
| 大图页 | 右键图片 → 同上两项（排在「另存为原件」下面） | 同上 |
| 大图顶栏 | 「混淆」/「解混淆」两个按钮 | **只换屏幕上的预览**，不生成文件，离开这张图即恢复 |

- 顶栏两个按钮是「先看一眼」用的：看着不对就翻页走了，什么都不会留下；
  要发给别人（或喂给小番茄）用右键那两项。
- 只对**图片**显示；只在**本机**显示（手机端点它等于在电脑上存一份，你拿不到）。
- **原图一个字节都不动**，副本另存一份。

### 副本在哪、长什么样

- 目录：原图同级的 **`_混淆\`** 子目录（图库不展开子目录，乱色块不会混进正常出图的列表）。
- 文件名：混淆 `原名_混淆.png`、解混淆 `原名_解混淆.png`；重名顺延 `-2`；来回多趟不叠后缀。
- 完成后底部提示条：「已生成混淆副本：xxx_混淆.png」+「打开文件夹」；点「详情」看位置、尺寸、格式。
- **副本不带任何生成参数** —— 混淆图要是还挂着原提示词，混淆就白做了。
- 输出是 **PNG（无损）**：混淆 → 解混淆可以**逐像素还原**，不像旧版走 JPEG 会掉一点精度；
  含透明通道的图也不再丢 alpha。

### 三条硬边界

1. **尺寸一变就废**。混淆图被缩放或裁剪过（微信「压缩后发送」、截图、贴进对话被自动缩图）就还原不回来 ——
   必须用「发文件」的方式传。
2. **单张上限 2000 万像素**，超了直接拒绝，不会自动缩图（一缩就永远对不上对方的图）。
3. **混淆不是加密**。规则公开，谁都能还原，它只防剧透和顺手转发。

### 画质与速度

- **全程无损**：PNG 原图 → 混淆 PNG → 解混淆 PNG，往返逐像素相同（MAE = 0）。
- 速度：处理在浏览器里做（OffscreenCanvas），1200 万像素约 1 秒内；不再需要现算曲线、
  也不再写曲线缓存（旧版的 `hunxiao_cache\` 目录**已经不用了**，可以直接删）。
- 不再需要 numpy：整条链路都不碰 Python 像素运算。
- 上限约 3355 万像素（32×1024×1024，预览与副本同一口径），超过会明确提示而不是自动缩图。

## 十七、常见问题

**Q：双击后没反应 / 打开很慢？**
首次启动需解压运行时并经杀软扫描，等 5~10 秒属正常。

**Q：双击后弹出一个「启动失败」的系统对话框，说写入检查失败？**
这是新版加在**建窗口之前**的预检：它先试着往 `%LOCALAPPDATA%\ComfyMediaViewer\backend` 写一个小文件
（写完立刻删掉，不碰你的配置和图片），写不进去就直接告诉你原因 —— 因为这种情况下继续启动必然是白屏，
而且连错误页都渲染不出来。
最常见的原因是**压缩包里的 EXE 被单独拖到别的文件夹**，它身上带着原目录的「低完整性」标记，
读得到旧文件、写不进新文件。**解法**：把发布 ZIP **重新解压**到一个新文件夹（桌面上最好），
运行解压出来的 EXE —— 不要只移动已经解开的单文件。关杀软、重启电脑都治不了这个。
对话框里的「详细记录」指向程序旁的 `ComfyMediaViewer-startup.log`（只有启动不顺才会生成；
正常启动不留任何文件，常驻日志在 `%LOCALAPPDATA%\ComfyMediaViewer\shell.log`）。
WebView 缓存目录写不进去**不会**拦你（只在日志里记一行），只有后端目录写不进才阻断。

**Q：界面显示还是旧的？**
按 `Ctrl+F5` 强制刷新浏览器页面。

**Q：删除的文件在系统回收站找不到？**
默认删进**应用内回收站**（顶栏 `⋯ 工具 → ♻ 回收站`），不是系统回收站。
想让它进系统回收站，去 **⚙ 设置 → 行为 → 删除去向** 改成 **Windows 回收站**。

**Q：端口被占了？**
自动换用下一个端口（地址栏端口会变），或 `--port` 固定。

**Q：下载的图片为什么没有生成参数了？**
下载默认抹元数据（保护提示词隐私）。要原图直接在"所在文件夹"取。

**Q：大图页按 P 没反应？**
确认焦点不在输入框；`P` 用于收起/展开右侧详情面板（原 `Tab` 已改到 `P`，避免破坏键盘遍历）；`/ ` 聚焦搜索，`Esc` 清空搜索。
