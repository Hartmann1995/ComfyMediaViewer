# ComfyMediaViewer

本地优先的 ComfyUI 出图浏览器：扫描出图目录、网格缩略图、点开看生成参数，
支持收藏分类、提示词搜索、元数据抹除下载与回收站删除。
单文件 Python 后端 + 原生 JS 前端（`frontend/`，零构建、零第三方依赖）即可运行。

## 功能

- **目录浏览**：自动探测 `ComfyUI/output`，支持子文件夹递归与收拢展示、面包屑导航
- **生成参数**：点开 PNG 显示模型、LoRA（仅统计实际启用的）、采样器、步数、CFG、
  Seed（自动沿连线解析真实种子值）、正/负提示词，一键复制
  （提示词只取文本本身：自定义 LoRA 节点槽位里的 `<lora:...>` 标签会被剥离，
  正负不跨侧串味；只有正向提示词的工作流，负向栏显示为空而不是复制正向 ——
  **千问 2.1 等「单节点双输出」工作流同样按此口径**，负向侧只认负向专属字段，不再把正向复制成负向）
- **常用目录可移除（2026-11-11）**：左栏「位置 → 根目录」下拉里，鼠标移到任一条上，
  右侧浮出 `×`，点它即从常用目录移除（只删列表项，不动磁盘、不切目录）。
  正在使用的那条不显示删除键 —— 先切到别的目录再清。此前这个列表只进不出，
  攒满 8 条后新目录会把老目录顶掉
- **LoRA 双站直链（2026-11-11）**：详情面板每条 LoRA 右侧给 `[R│C] ↗` 分段胶囊（约 46px）——
  图里有 `Lora hashes` 就按哈希去 `civitai.com` / `civitai.red` 查对应版本，没有就按名字搜索；
  匹配到就直指模型页，匹配不到会明说并给按名搜索的链接，**不拿同名模型冒充**。
  只读查询：只把 LoRA 名或哈希发给 C 站，本地只读 LoRA Manager 的配置与数据库；
  桌面版点击用系统默认浏览器打开，后台查询不阻塞看图
- **收藏分类**：星标收藏 + 自定义分类，只看收藏视图
- **提示词搜索**：后台索引（自动增量刷新，约 30 秒内即可搜到新图），
  按提示词/模型/LoRA 名搜索全部历史出图
- **下载抹元数据**：下载的 PNG/JPG 字节级剥离提示词/工作流（像素不变）
- **删除**：单张或批量（首页右键空白处开启批量模式），移入应用内回收站可还原（保留 30 天）
- **视频预览**：mp4/webm 等浏览器可直接播放的格式（自绘控制条：进度 / 时间 / 音量，跟随深浅主题）；**点开不自动播放**、停在首帧当海报（暂停 / 继续：控制条 ▶、空格、点画面），缩略图与胶片条渲染**真首帧**，`.mp4`/`.webm`/`.mov`/`.m4v`/`.mkv`/`.avi` **内嵌的生成参数可读可搜**
- **出图统计**：顶栏 `⋯ 工具 → 出图统计`，看**每日产出日历热力图**（GitHub 贡献图式，
  一列一周、颜色越深当天出图越多、悬停看「日期 · 张数」，**没出图的日子也留着空格**）
  + 模型 / 采样器 / 尺寸 Top 10 占比条
- **重复图检测**：查重找内容相同或相近的图，按组勾选保留一张、一键清理其余
- **失效标签可清理（2026-11-15）**：左栏「还有 N 个标签已失效」右侧给「清理」按钮，
  二次确认写明**只删记录、不动图片**；盘掉线回 `409 unreadable`、安全阀拦下回
  `409 *_guard`，绝不放行；换根不误清旧根
- **查重可扫全库（2026-11-15）**：扫描范围选「前 3000 / 全库」，单张哈希 42 → 7 ms，
  全库约 1.5 分钟、有磁盘缓存后秒级；结论带分母（覆盖全库 / 已达上限 · 读不出多少张）
- **卡片层与位置刻度（2026-10-23）**：卡片用独立的 10px 圆角 + 主题描边（深/亮各一套，静止不加投影）；
  文件名默认只在**滚动中 / 悬停 / 键盘聚焦**时出现（松手约 0.4 秒收起，程序化跳转不闪），
  右下角同时给「第 N / 共 M 张 · 百分比」刻度（静止 1.2 秒后只留百分比）；
  ⚙ 设置 → 外观 → 卡片信息 里可改回「常显文件名」或关掉「滚动时显示」

## 运行

零第三方依赖（有 Pillow 时自动生成缩略图缓存，强烈建议安装）：

```bash
python server.py                          # 自动探测默认目录
python server.py --root "D:\我的图片"     # 指定根目录
python server.py --port 8765 --no-browser # 固定端口、不开浏览器
```

仅监听 127.0.0.1，文件访问被限制在当前根目录内；`/api/file` 只对图片/视频内联渲染，
其他扩展名一律作为附件下载（并带 `X-Content-Type-Options: nosniff`），避免同源执行脚本。

## 打包为单文件 exe

```bash
pip install pyinstaller pillow
python make_icon.py        # 生成 app.ico（已附带可跳过）
pyinstaller ComfyMediaViewer.spec --noconfirm
# 产物在 dist/ComfyMediaViewer.exe
```

## 数据存储

收藏、提示词索引、缩略图缓存存放在 `%LOCALAPPDATA%\ComfyMediaViewer\`。
备份/迁移收藏只需拷贝其中的 `favorites.json`；**重装系统前请备份该目录**。

## 已知限制

- 目录列表为服务端全量扫描（rglob + stat）后一次性返回，单个目录积累到数万
  文件后加载会明显变慢；建议按子目录浏览或定期归档旧图
- 收藏/索引无跨机同步
- **局域网访问已开通**（2026-11-07）：设置 → 数据 → 局域网访问，开启后显示 **6 位配对验证码**，手机或**另一台电脑**打开地址输码即可（不需摄像头扫码）；远端**只读**（可浏览 / 搜索 / 收藏 / 打标签 / 下载，不能删除、换目录、重建索引），仅限同一 Wi-Fi，不暴露公网；进过一次就记住设备，重启不用重输
- 单目录数万文件时列表仍是一次性返回 + 分段渲染，虚拟滚动 / 后端分页待评估
